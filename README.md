Проект посвящён автоматической кластеризации сигналов, полученных со сцинтилляционного детектора.  
Цель работы — разделить **23 479 осциллограмм** на три группы:

- **Класс 0** — первый тип физических событий;
- **Класс 1** — второй тип физических событий;
- **Класс 2** — аномальные, смешанные или трудно классифицируемые сигналы.

Задача решается методами **машинного обучения без учителя** с последующей физической интерпретацией результатов кластеризации.

---

## Описание задачи

Сцинтилляционные детекторы применяются в задачах радиационного контроля, ядерной энергетики, экспериментальной физики и регистрации различных типов ионизирующего излучения.  
Одной из важных задач при обработке сигналов таких детекторов является разделение событий, соответствующих разным типам частиц, например гамма-квантам и нейтронам.

Сигналы детектора представлены в виде осциллограмм. Каждый сигнал содержит 500 временных отсчётов, отражающих изменение амплитуды во времени. Ручной анализ такого количества сигналов практически невозможен, поэтому используется автоматическая кластеризация.
