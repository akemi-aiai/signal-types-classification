# Signal Types Classification

Данный проект посвящён задаче автоматической кластеризации сигналов, полученных со сцинтилляционного детектора. Основная цель работы — разделить набор из 23 479 сигналов на три группы с помощью методов машинного обучения без учителя.

Два кластера должны соответствовать различным типам зарегистрированных частиц — гамма-квантам и нейтронам, а третий кластер предназначен для сигналов, которые не удаётся однозначно отнести к одному из основных классов. К таким сигналам могут относиться выбросы, шумовые события, смешанные импульсы или аномальные формы сигналов.

## Актуальность задачи

Разделение сигналов разных типов является важной задачей в ядерной физике, радиационном контроле, экспериментальной физике и смежных областях. Сцинтилляционные детекторы применяются для регистрации различных видов ионизирующего излучения, однако получаемые сигналы часто имеют сложную форму, могут перекрываться и содержать шумы.

Ручной анализ десятков тысяч сигналов практически невозможен, поэтому возникает необходимость в автоматизированных методах обработки данных. Использование алгоритмов кластеризации позволяет выявлять внутреннюю структуру данных без заранее заданных меток классов, отделять физически значимые группы сигналов и обнаруживать аномальные события.

## Цель проекта

Целью проекта является построение воспроизводимого машинно-обучающего решения для автоматической кластеризации сигналов сцинтилляционного детектора на три группы:

* сигналы первого типа частиц;
* сигналы второго типа частиц;
* аномальные или неоднозначные сигналы.

## Этапы работы

- загрузка данных;
- EDA;
- коррекция baseline;
- инверсия отрицательных импульсов;
- извлечение признаков;
- анализ PSD-признаков;
- сравнение моделей кластеризации;
- финальная PSD-кластеризация

Были протестированы следующие модели: KMeans, MiniBatchKMeans, GaussianMixture, Birch, IsolationForest. Финальное решение основано на локальном PSD-разделении.

## Итог

В результате выполнения проекта была построена модель кластеризации, позволяющая автоматически разделять сигналы сцинтилляционного детектора на три группы. Полученные кластеры интерпретируются как два основных типа частиц и отдельная группа аномальных или неоднозначных сигналов.

Проект демонстрирует применение методов машинного обучения без учителя к задаче анализа физических сигналов и может рассматриваться как основа для дальнейшего развития системы автоматической классификации сигналов в экспериментальной физике и радиационном контроле.
