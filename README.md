Проект решает задачу кластеризации сигналов сцинтилляционного детектора.  Нужно разделить 23 479 сигнала на три класса: два основных типа сигналов и отдельный класс аномалий.

## Данные

Каждый сигнал представлен 500 точками осциллограммы.  
Первые 4 столбца исходного файла содержат служебную информацию.

## Этапы работы

- загрузка данных;
- EDA;
- коррекция baseline;
- инверсия отрицательных импульсов;
- извлечение признаков;
- анализ PSD-признаков;
- сравнение моделей кластеризации;
- финальная PSD-кластеризация

Были протестированы следующие модели: KMeans, MiniBatchKMeans, GaussianMixture, Birch, IsolationForest. Финальное решение основано на локальном PSD-разделении.
